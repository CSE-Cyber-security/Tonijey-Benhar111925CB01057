# Simple Calculator

## Objective
A beginner-friendly Python calculator that performs addition, subtraction, multiplication, and division.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles invalid menu choices
- Handles non-numeric input
- Prevents division by zero
- Repeats until the user chooses Exit

## Requirements
- Python 3 installed
- VS Code or any Python editor (optional)

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   ```bash
   python calculator.py
   ```

   On some systems, use `python3 calculator.py`.
